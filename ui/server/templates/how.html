Auditor in a Box

Using LLMs to provide privacy-preserving and verifiable audits.

  1. Only runs signed plans. The lab and the auditor agree on a plan and both sign it. The box runs nothing else.
  2. Checks what comes in. The box verifies the logger's signature on the records and reads only the logs the plan names.
  3. Only a short report comes out. The plan fixes what the report may hold, and the box signs it. The logs never leave.
  4. Attested. The box runs in a confidential VM. The chip states which image is running, and anyone can check it.
