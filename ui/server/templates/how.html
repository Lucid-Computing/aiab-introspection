Auditor in a Box

Using LLMs to provide privacy-preserving and verifiable audits.

  1. The lab and the auditor agree on a plan: the question, the examples, the threshold, the code and the prompt.
  2. Both sign the plan with their own private keys. Any change after that voids both signatures.
  3. The plan, signed by the lab and the auditor, is built into a container image. The build is reproducible, so anyone can check that the image matches the plan.
  4. The image runs in a confidential VM on Tinfoil. The hardware encrypts its memory, so not even the server's operator can read what's inside.
  5. The chip signs a report, checkable by anyone, that the image built from the plan they signed is running.
  6. The logging proxy signs the lab's recorded model traffic with its own key and sends it to the box.
  7. The box runs the plan over the logs with the agreed model.
  8. Only a short answer comes out. The logs are held only in memory, never written to disk, and dropped once the answer is signed.
  9. The box signs the answer, so anyone can check it came from this plan and wasn't changed. The auditor checks it offline.
