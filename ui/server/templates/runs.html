Check the box independently (attestation)

The manifest is what the box says about itself. Attestation is the hardware's signed statement of the same thing. The auditor's own check, from static/, with values approved independently, never copied from the box:

uv run python -m auditor.baked --folder ../plan pin-identity --release deploy/tinfoil/audit/release.json \
    --token-file /absolute/path/auditor.token --output /tmp/anchor.json

Where the credentials come from

lab.token is the lab's API token for the box and logger.key is the demo logger's private key, the one whose public key the box pins as the logger. Both are held by the box's operator (Jon) under ~/.local/share/aiab-audit-demo/ on his host. Copy them to the same path on the machine running this UI, or point AIAB_DEMO_KEYS at a folder holding them. Never commit them.
