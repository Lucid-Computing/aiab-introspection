The manifest is what the box says about itself. Attestation is the hardware's signed statement of the same thing. The auditor's own check, from static/, with values approved independently, never copied from the box:

uv run python -m auditor.baked --folder ../agreements/{{ chosen or "NAME" }} pin-identity --release deploy/tinfoil/audit/release.json \
