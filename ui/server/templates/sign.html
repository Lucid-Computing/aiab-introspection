05 — Sign

Sign

Steps 5 and 6 of the flow. The UI never holds a private key. Each party signs the plan digest on its own machine and uploads the resulting file; the UI verifies it against the pinned public key and stores it in plan/signatures/. The first uploaded signature freezes the plan. Any edit after that would make the signature stale, which is what CI checks.
