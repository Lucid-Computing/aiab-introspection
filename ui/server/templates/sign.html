  1. Sign it, one command on your own machine (needs OpenSSL 3; on a Mac, brew install openssl, the built-in one cannot do this): 
    printf 'AIAB/plan-bundle/v1\0{"plan_digest":"%s"}' {{ view.digest }} > /tmp/aiab-msg && openssl pkeyutl -sign -inkey ~/{{ user.party }}.pem -rawin -in /tmp/aiab-msg | base64
  2. Paste the line it prints into your card below and press Verify and store.
No key yet, or no OpenSSL 3?

Make a key pair once, then submit the public key it prints in your card below:

openssl genpkey -algorithm ed25519 -out ~/{{ user.party }}.pem
openssl pkey -in ~/{{ user.party }}.pem -pubout -outform DER | tail -c 32 | base64

Development keys from make dev-keys are already on file; their key is ~/.aiab-dev/{{ user.party }}.pem, so use that path in the sign command instead of ~/{{ user.party }}.pem.

Without OpenSSL 3, sign_digest.py (Python 3 with the cryptography package) does the same. Make a key and print its public key, then sign; the last line submits the signature for you instead of pasting it:

python3 sign_digest.py keygen --out ~/{{ user.party }}.key
python3 sign_digest.py sign --digest {{ view.digest }} --key ~/{{ user.party }}.key
python3 sign_digest.py sign --digest {{ view.digest }} --key ~/{{ user.party }}.key --party {{ user.party }} --user {{ user.username }} --submit {{ request.base_url }}a/{{ aid }}/sign/upload

To check the digest before signing, download plan.zip, the exact files it covers, and run this; it must print the digest above:

python3 sign_digest.py digest plan.zip
